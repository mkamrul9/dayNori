# @daynori/design-tokens

Semantic color, typography, spacing, radius, and elevation tokens for Daynori.

## Status

Established in Phase 01. Exports:

- Semantic color palettes for `light` and `dark` themes
- Standard spacing scale (`4`, `8`, `12`, `16`, `24`, `32`, `48`)
- Modest rounded corner radii (`8`, `12`, `16`)
- Typography sizing scales and line heights

Refer to [the design system documentation](../../docs/design/design-system.md) for rationale and contrast targets.
