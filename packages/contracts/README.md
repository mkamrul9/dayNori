# @daynori/contracts

Versioned Zod validation schemas and DTO contracts for Daynori APIs and clients.

## Status

Established in Phase 01. Exports:
- `HealthResponseSchema` / `HealthResponse`: Standard service liveness and version shape
- `SmokeResponseSchema` / `SmokeResponse`: Verification route schema
- `ErrorResponseSchema` / `ErrorResponse`: Standard API error contract

See [API conventions](../../docs/architecture/api-conventions.md) and [repository layout](../../docs/engineering/repository-layout.md).
