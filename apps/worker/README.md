# @daynori/worker

Durable background job processor and asynchronous worker for Daynori.

## Status

Established in Phase 01. Provides:

- `DaynoriWorker`: Lifecycle manager and job dispatcher
- Execution loop for asynchronous jobs, reminders, and cleanup tasks
- Scripts: `pnpm build`, `pnpm typecheck`, `pnpm dev`, `pnpm start`

See [operations and scaling](../../docs/architecture/operations-and-scaling.md) and [integrations and reminders](../../docs/architecture/integrations-and-reminders.md).
