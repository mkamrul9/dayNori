# @daynori/web

Next.js responsive browser application for Daynori.

## Status

Established in Phase 01. Provides:

- Next.js App Router structure with semantic layout and design token styling
- Smoke health route at `/api/health` validating against `@daynori/contracts`
- Scripts: `pnpm dev`, `pnpm build`, `pnpm start`, `pnpm typecheck`

See [system overview](../../docs/architecture/system-overview.md) and [repository layout](../../docs/engineering/repository-layout.md).
