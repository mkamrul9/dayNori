# Two visual directions

Both directions keep Daynori’s recognizable paper / ink / teal / amber identity and existing logo mark (folded D). They are not two near-identical palettes.

## A — Warm notebook

- Warm paper `#F7F5EF`, white surfaces, generous padding, softer radii (10–18px).
- Editorial hierarchy: larger titles, comfortable reading measure (~42rem), quieter borders.
- Spacious writing surfaces for Journal/Notes; teal actions with restrained amber emphasis.
- Dark: deep ink background with soft teal actions (aligned with current shipped token roles).

**Strengths:** Writing comfort, calm first-use, Journal quality bar, Bangla line-height room.  
**Risks:** Can feel less “fast scan” for dense Plan/Library lists if spacing stays maximal.

## B — Crisp utility

- Cooler paper-gray `#F3F5F4`, stronger structural borders, tighter density (6–10px radii).
- Clearer column rails and list dividers; faster scanning for tasks and library rows.
- Same teal/amber semantic roles with slightly deeper teal `#0F5F58` for sharper action contrast on cool paper.
- Dark: near-black teal surfaces with crisp separators.

**Strengths:** Organization clarity, Plan/Library density, alignment discipline (Linear-like hierarchy without tracker chrome).  
**Risks:** Can feel colder for Journal if not carefully softened in editor surfaces.

## Shared screens compared

Welcome/sign-in · Today · Task editor · Library · Journal editor · Help/tour · Assistant — each in light/dark via the prototype review bar; desktop and ~360px via browser resize / capture script.
