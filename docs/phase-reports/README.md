# Phase reports

Each completed phase has a report named phase-NN.md based on [the template](../templates/phase-report.md). The report is committed with that phase's code and documentation.

Reports record implemented scope, exact validation evidence, manual checks, remaining limits, decisions, and handoff. They are separate from generated [phase specifications](../roadmap/README.md) so regeneration cannot erase completion evidence.

Phase 00 establishes planning only. Reports for future phases must be created when their work is performed, not prefilled with imagined results.
