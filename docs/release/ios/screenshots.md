# Screenshot requirements

Apple product-page screenshots must show the **actual** application on required device sizes.  

## Capture rules for Daynori

- Capture from a running Simulator or device build of the RC under review.
- Use synthetic fixtures only.
- Do **not** show vault, rooms/chat, live AI, Drive, or purchase paywalls as enabled product features.
- Prefer Today, Plan, Library, Journal, and Settings (account deletion entry visible in Settings/support paths as appropriate).
